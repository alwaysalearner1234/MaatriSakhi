MaatriSakhi narrative workflow (Portal -> OpenCode + Muse Spark 1.3 Contributor Free)
============================================================

DOCX is an OUTPUT, never an input. The portal submission is
the only clinical source of truth.

Step 0 (done in portal/backend): python generator.py submit <portal_submission.json>
  Wrote: C:\Users\lidiy\Downloads\MaatriSakhi\source.json

Step 1 (done): python generator.py prepare
  Wrote: C:\Users\lidiy\Downloads\MaatriSakhi\output\narrative_request.json

Step 2: in OpenCode, using model muse-spark-1.3-contributor-free, paste the
  'instructions' as the system prompt and the 'input' as the
  user message from narrative_request.json (or attach the file
  and ask for the PRECONCEPTION narrative). Ask the model to
  return ONLY the JSON object matching the supplied schema.
  Save that JSON object to output/draft_narrative.json
  (create the output/ folder if needed).

Step 3: python generator.py build output/draft_narrative.json
  This validates the narrative against the schema and writes
  C:\Users\lidiy\Downloads\MaatriSakhi\result.json and output/preconception.docx from the SAME
  validated JSON.

If validation reports errors, paste them back into OpenCode and
ask for a corrected JSON object, then repeat Step 3.

Important: validation checks structure and formatting only. A
clinician must review the report against the source record
before clinical use. Never read clinical info from the DOCX.
